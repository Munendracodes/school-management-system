# School Management System

Multi-tenant School Management System built using:

- FastAPI
- PostgreSQL
- Redis
- Docker
- SQLAlchemy 2.0
- Alembic

## Features

- Multi-tenant architecture
- JWT authentication (upcoming)
- RBAC (upcoming)
- Student management
- Teacher management
- Attendance
- Homework
- Notifications

## Local Setup

### Start containers

```bash
docker compose up --build
```
